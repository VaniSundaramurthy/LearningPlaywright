# Learning Playwright - JavaScript Fundamentals

This repository contains JavaScript fundamentals and learning materials as a foundation for Playwright test automation.

## 📚 Project Structure

### Chapter 01: Basics
Introduction to JavaScript basics and core concepts.
- `01_Basics_java.js` - First JavaScript script
- `02_JS.js` - JavaScript fundamentals
- `03_JS_Commands.js` - Common JavaScript commands
- `04_hotcode.js` - Code snippets and examples
- `05_JS_Basic` - Basic JavaScript concepts
- `06_Identifiers.js` - Understanding identifiers
- `08_Comments.js` - JavaScript commenting practices

### Chapter 03: Identifiers & Literals
Deep dive into JavaScript identifiers and literal values.

### Chapter 04: JavaScript Functions
Understanding functions and variable declarations.
- `10_Functions.js` - Function basics and definitions
- `11_var_explained.js` - Variable declaration with var
- `12_let_explained.js` - Block-scoped let declaration
- `13_const_explained.js` - Constant declaration with const
- `14_hoisting.js` - Variable hoisting concepts
- `15_hoisting_function.js` - Function hoisting behavior

## 🎯 Learning Objectives

- Master JavaScript fundamentals
- Understand variable declarations (var, let, const)
- Learn about function definitions and usage
- Grasp concepts like hoisting and scope
- Build a strong foundation for Playwright automation

## 🚀 Getting Started

1. Clone this repository
2. Navigate through chapters in sequential order
3. Run JavaScript files using Node.js:
   ```bash
   node <filename>.js
   ```

## 📝 Prerequisites

- Node.js installed on your system
- Basic understanding of programming concepts
- Text editor or IDE (VS Code recommended)
